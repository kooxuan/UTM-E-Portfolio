🌐 SECJ3104 – Application Development

This folder contains our group project system documentation for SECJ3104 Application Development at Universiti Teknologi Malaysia.

The project is titled “NormNinja: Normalize Your Learning, Elevate Your Skills,” which is a web application for a database learning platform developed by Team Data Voyagers.


📌 Project Components

Authentication Module – Secure account management with role-based access for Students, Teachers, and Admins. 

Learning Material Module – Centralized library for teachers to upload resources and for students to easily browse, view, or download educational content.

Quiz Module – Comprehensive assessment tool supporting quiz creation, timed attempts, and detailed result tracking for performance evaluation.

Game Module – Interactive gamified learning feature where students can play educational games and track their rankings on a leaderboard.

Forum Module – Community discussion board enabling users to create posts, reply to threads, and collaborate on academic topics.

Activity Module – Performance dashboard and calendar management to help track student progress, recent activities, and upcoming events.


✨ Highlights

Follows the Model-View-Controller (MVC) architectural design pattern for clean structure and modularity.

Developed using the Laravel PHP framework with a MySQL database hosted on the Aiven cloud platform.

Responsive and interactive user interface built with Blade templates, Tailwind CSS, and Alpine.js.

Integrates gamification (leaderboards and scoring) to motivate active participation and boost student engagement.

Provides dedicated, data-driven dashboards for both teachers and students to monitor real-time learning progress and performance analytics.


🎯 Purpose
To design and develop an interactive, centralized e-learning platform that goes beyond standard content delivery by integrating gamification, real-time assessments, and performance tracking, ultimately making the teaching and learning process more engaging and data-driven for both tutors and students.

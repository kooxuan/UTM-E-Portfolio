🤖 SECJ3553 – Artificial Intelligence

This folder contains our group project assignments for SECJ3553 Artificial Intelligence at Universiti Teknologi Malaysia.

The project theme is Healthcare, focusing on MindCare AI – an intelligent mental health support chatbot.


📌 Project Components

Proposal – Defines the problem, AI solution, goals, and design thinking process

Assignment 1 – Knowledge Representation (First-Order Logic rules for depression, anxiety, safety risk, coping strategies)

Assignment 2 – State Space Search (formulation of chatbot reasoning as search problem with states, actions, goals)

Assignment 3 – Intelligent Agent & PEAS Model (performance measures, environment, sensors, actuators, proof of concept)

Proof of Concept (POC) – Demonstrates system behavior in practice

✨ Highlights

- Knowledge base using First-Order Logic

- State space search for reasoning and decision-making

- Safety-first design with high-risk detection and emergency protocols

- Intelligent agent modeled with PEAS framework

- Goal: Provide safe, supportive, and explainable mental health guidance

🎯 Purpose

To design and simulate an AI-driven healthcare chatbot that demonstrates core AI concepts (KR, search, agents) while addressing real-world challenges in mental health support.

🧬 SECB2103 – Bioinformatics I

This folder contains our group project for SECB2103 Bioinformatics I at Universiti Teknologi Malaysia.

The project, titled “Find a Gene”, explores computational methods to identify and analyze novel genes using bioinformatics tools.


✨ Project Highlights

🔎 BLAST searches (TBLASTN, BLASTP) for gene discovery

🧪 Sequence extraction and validation of novel proteins

🧬 Multiple sequence alignment (MSA) using MAFFT/Clustal

🌳 Phylogenetic tree construction with MEGA

📊 Comparative analysis and discussion of evolutionary relationships


🎯 Purpose

To apply bioinformatics techniques in gene discovery and analysis, demonstrating how computational tools can identify novel proteins and place them within evolutionary context.

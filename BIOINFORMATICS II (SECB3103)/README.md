🧬 Bioinformatics II

This folder contains my lab exercises, assignments, and the final machine learning project for Bioinformatics II.

The course focuses on practical applications of bioinformatics tools and Python libraries to extract valuable insights from genomics, proteomics, and clinical data.


📌 Project & Coursework Components

Machine Learning Project (Alzheimer's Disease Prediction) – A clinical decision support web app built with Streamlit and Scikit-Learn. It handles data preprocessing, exploratory data analysis (EDA), and evaluates multiple ML models (Logistic Regression, Decision Tree, SVM, KNN) to predict Alzheimer's based on top clinical features.

Assignment 1 (Sequence Alignment) – A web application implementing Global (Needleman–Wunsch) and Local (Smith–Waterman) sequence alignment algorithms using dynamic programming.

Assignment 2 (Pattern Matching & Distances) – Implementation of exact string matching algorithms (Naive, Boyer-Moore) and sequence distance computations (Hamming, Edit Distance).

Lab 1 (Protein Sequence Analysis) – Automated retrieval of UniProt protein sequences and basic property analysis (amino acid composition, molecular weight, isoelectric point) using Biopython.

Lab 2 (3D Protein Structure Analysis) – PDB structure retrieval, calculating Center of Mass and Radius of Gyration, and interactive 3D molecular visualization using py3Dmol.

Lab 3 (Protein-Protein Interactions) – PPI network data retrieval from BioGRID/STRING and network graph visualization and centrality measure analysis using NetworkX.


✨ Highlights

Applied Machine Learning for clinical prediction, complete with automated model evaluation (Accuracy, F1, AUC), ROC curve visualization, and feature importance extraction.

Hands-on development of interactive Streamlit web applications for real-time biological data analysis.

Implementation of fundamental computational biology algorithms from scratch.

Integration of powerful Python libraries including Pandas, Biopython, Scikit-Learn, NetworkX, and py3Dmol.


🎯 Purpose

To gain hands-on experience with advanced bioinformatics methodologies, equipping students with the essential resources and solid foundation needed to interpret complex biological data and build practical computational pipelines for different clinical and genomic scenarios.

🔢 Computational Mathematics – Group Assignments

This folder contains coursework for SECI1113 Computational Mathematics at Universiti Teknologi Malaysia.

It showcases problem-solving techniques in linear algebra, vector spaces, numerical methods, and error analysis, combining both manual calculations and Python implementations.


✨ Included Assignments

Assignment 1 – Matrix operations, Gaussian elimination, LU factorization, vector computations

Assignment 2 – Vector space axioms, subspaces, spanning sets, basis and dimension, linear transformations

Assignment 3 – Error analysis, root-finding methods (Bisection, Secant, Newton), numerical approximations

Assignment 4 – Eigenvalues/eigenvectors (Power & Shifted Power methods), interpolation, least squares, numerical differentiation, integration techniques


🎯 Purpose

These assignments strengthen understanding of computational mathematics concepts and their applications in computer science.
They highlight the balance between theoretical foundations and practical numerical methods, preparing students for advanced problem-solving in scientific computing and bioinformatics.

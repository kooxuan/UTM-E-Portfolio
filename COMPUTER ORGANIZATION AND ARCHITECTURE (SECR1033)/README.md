🖥️ Computer Organization & Architecture Project

This project was developed as part of COA coursework at Universiti Teknologi Malaysia.

It focuses on applying computer organization and architecture concepts to design and implement a practical system, showcasing how theoretical principles can be translated into real-world applications.


✨ Highlights

Demonstrates core COA principles (logic, memory, control, and processing)

Implements structured design with clear modular components

Emphasizes efficiency, accuracy, and practical usability

Includes documentation and circuit/system diagrams for clarity


🎯 Purpose

The project bridges theory and practice, helping students understand how low-level hardware concepts support higher-level system functionality. It serves as both a learning exercise and a foundation for more advanced digital system design.

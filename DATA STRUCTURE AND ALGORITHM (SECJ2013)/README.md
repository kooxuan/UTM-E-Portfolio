📘 Data Structures and Algorithms – Mini Project

This repository contains our group project for SECJ2013 Data Structures and Algorithms at Universiti Teknologi Malaysia.

The project demonstrates how fundamental data structures and algorithms can be applied in solving practical problems through programming.


✨ Highlights

Use of classes and objects to structure the program

Application of queue operations to manage sequential data

Integration of algorithmic concepts for navigation and history tracking

Implementation of menu-driven interaction with loops and switch-case control

Focus on team collaboration and equal contribution across all members


🎯 Purpose

The project emphasizes the importance of data structures (like queues) and algorithmic thinking in building efficient, user-friendly systems.

It serves as a practical exercise to strengthen programming skills, teamwork, and understanding of how abstract concepts translate into real-world applications.

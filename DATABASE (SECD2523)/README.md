🗄️ Database Project – Online Shopping Management System
This repository contains our group project for SECD2523 Database at Universiti Teknologi Malaysia.
The project focuses on designing and implementing a database-driven online shopping management system, covering the full cycle from requirements analysis to conceptual and logical design, SQL implementation, and testing.


✨ Project Phases

Phase 1 – Proposal & Feasibility

Background study, problem statement, proposed solutions

Technical, operational, and economic feasibility studies

Objectives, scope, WBS, Gantt chart, requirement analysis

Phase 2 – Conceptual Design

Data Flow Diagrams (Context, Level 0, Child)

Business rules, data & transaction requirements

Conceptual ERD, Enhanced ERD (EERD), Data Dictionary

Phase 3 – Logical Design & SQL

Logical ERD, normalization (up to BCNF)

Relational schemas

SQL statements (DDL & DML) with sample data

User interface mapping



🎯 Purpose

The project demonstrates how database concepts can be applied to build a robust e-commerce platform.

It emphasizes data integrity, normalization, transaction management, and user experience, while aligning with real-world business needs such as inventory tracking, order processing, payment management, and customer engagement.

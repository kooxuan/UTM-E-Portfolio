🚀 Lift Electronic Controller System

This project was developed as part of Digital Logic (SECR1013-03) at Universiti Teknologi Malaysia.

It demonstrates the design and implementation of a lift electronic controller system using combinational and sequential circuits.


✨ Features

Accurate floor selection with 3-bit up/down counter

4-digit password protection for security

Emergency stop function for passenger safety

Weight limit detection with alarm and LED indicator

7-segment display showing current floor levels


🎯 Purpose

The system prioritizes precision, safety, and security while showcasing practical applications of digital logic design. It integrates key components such as decoders, comparators, counters, and display units to deliver a reliable and user-friendly lift controller.

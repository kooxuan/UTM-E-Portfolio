🌐 SECR1213 – Network Communications

This repository contains group project work for SECR1213 Network Communications at Universiti Teknologi Malaysia.

The project focuses on network design and infrastructure planning for a new faculty building, including:

🏢 Floor plan setup (labs, hybrid classroom, student lounge)

🔌 LAN device selection (routers, switches, firewalls, servers, access points)

📊 Feasibility studies (technical, operational, economic)

🔒 Security and scalability considerations

📝 Meeting minutes and collaborative documentation


🎯 Purpose

To apply network communication concepts in a real-world scenario, ensuring efficient, secure, and scalable connectivity for academic and administrative needs.

⚙️ SECR2043 – Operating Systems

This folder contains our group project for SECR2043 Operating Systems at Universiti Teknologi Malaysia.

The project demonstrates process synchronization using Peterson’s Algorithm in a real-world scenario of two computers sharing a single printer.


✨ Project Highlights

🖨️ Simulation of two computers accessing a shared printer

🔒 Implementation of Peterson’s Algorithm for mutual exclusion

🧵 Thread-based simulation using Pthreads in C

✅ Ensures synchronization conditions: mutual exclusion, bounded waiting, progress

📊 Output analysis showing conflict-free resource sharing


🎯 Purpose

To apply synchronization concepts in operating systems by solving a shared resource conflict, highlighting how Peterson’s Algorithm ensures fairness and prevents race conditions in concurrent environments.

🧠 SECB3203 – Programming for Bioinformatics

This folder contains our group project for SECB3203 Programming for Bioinformatics at Universiti Teknologi Malaysia.

The project is titled “Alzheimer's Disease Prediction,” which focuses on developing a machine learning-based clinical decision support system using comprehensive clinical, demographic, and lifestyle data.  

📌 Project Components
- Data Preprocessing Pipeline – Includes handling missing values with median imputation, feature removal for weak predictors, age binning, Min-Max/Z-score normalization, and one-hot encoding.
- Exploratory Data Analysis (EDA) – Features target distribution visualization, descriptive statistics, ANOVA testing for feature relevance, and correlation heatmaps to identify relationships.
- Model Development – Implementation of four machine learning classification algorithms: Logistic Regression, Decision Tree, Support Vector Machine (SVM), and K-Nearest Neighbors (KNN).
- Model Evaluation – Comprehensive testing using Accuracy, Precision, Recall, F1-Score, Confusion Matrices, and ROC-AUC curves.

✨ Highlights
- Developed a robust binary classification model to predict Alzheimer's disease using a dataset of 2,149 patient records.
- The Decision Tree model achieved the best overall performance with an accuracy of 88.84% and an AUC of 0.92.
- Extracted feature importance, identifying MMSE scores and ADL (Activities of Daily Living) as the strongest clinical predictors for Alzheimer's disease.
- Built utilizing Python and powerful data science libraries, including Pandas, NumPy, Scikit-learn, Matplotlib, and Seaborn.

🎯 Purpose
To demonstrate the practical application of programming and machine learning techniques in bioinformatics for data cleaning, interpretation, and predictive modeling. It serves to illustrate how computational models can assist healthcare professionals in early disease detection and risk assessment.

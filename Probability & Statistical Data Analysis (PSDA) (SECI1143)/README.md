📊Probability & Statistics for Data Analytics Project

This project was developed as part of PSDA coursework at Universiti Teknologi Malaysia.

It applies probability and statistical methods to analyze data, solve problems, and demonstrate practical applications of data analytics concepts.


✨ Highlights

Implements statistical techniques for data analysis and visualization

Applies probability models to real-world scenarios

Focuses on accuracy, clarity, and practical usability

Includes documentation, calculations, and results for reference

🎯 Purpose

The project bridges theory and practice in data analytics, helping students understand how probability and statistics can be applied to decision-making, problem-solving, and system design. It serves as both a learning exercise and a foundation for more advanced analytics projects.

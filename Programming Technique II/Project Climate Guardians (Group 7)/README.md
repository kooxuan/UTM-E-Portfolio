🌍 Climate Action – Carbon Footprint Calculator

This project was developed as part of Programming Technique II (SECJ1023) at Universiti Teknologi Malaysia.

Our goal is to support SDG 13: Climate Action by creating a C++ program that helps users calculate their carbon footprint.

✨ Features

Input daily activities (transportation, energy usage, dietary habits)

Calculate and track personal carbon footprint

Provide insights to encourage sustainable practices


🎯 Purpose

This tool raises awareness about environmental impact, motivates individuals and communities to adopt greener habits, and supports governments and educators in promoting sustainability.

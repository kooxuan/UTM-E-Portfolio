💻 SECJ2203 – Software Engineering

This folder contains our group project for SECJ2203 Software Engineering at Universiti Teknologi Malaysia.

The project documents the design and development of the MindWell Self-Help System, a mental health support platform.


✨ Project Highlights

📱 AI-powered chatbot for self-diagnosis

🎮 Gamification features (points, badges, rewards)

🧰 Personalized toolbox (breathing exercises, journaling, skill-building tools)

📊 Progress tracking and diagnostic trends

🔒 Secure, user-friendly interface with strong data privacy


🎯 Purpose

To apply software engineering principles (requirements analysis, design, architecture, testing, documentation) in building a system that promotes accessible mental health management.

📚 System Analysis and Design – Systech Group Projects

This folder contains our coursework for SECD2613 System Analysis and Design at Universiti Teknologi Malaysia.

It documents the different phases of our project work, from planning and requirement gathering to analysis, design, and implementation.


✨ Included Projects

Phase 1 – Project Proposal & Planning

Phase 2 – Information System Gathering & Requirement Analysis

Phase 3 – System Analysis & Design (Logical & Physical DFDs, Specifications, Wireframes)

Assignments – Feasibility studies, WBS, PERT/Gantt charts, cost-benefit analysis, and case studies


🎯 Purpose

These projects demonstrate how to apply system analysis and design methodologies to real-world problems.
They cover requirement gathering, process modeling, feasibility studies, and system design, providing a complete view of the SDLC (System Development Life Cycle) in practice.
